DiPAut: A Tool for Checking Differential Privacy of Online Randomized Algorithms

Bishnu Bhusal, Rohit Chadha, A. Prasad Sistla, Mahesh Viswanathan

Zenodo, 2023

Software release

DOI Code and resources Cite this work Summary (Markdown)

What this work contributes

Provides the DiPAut software artifact for checking differential privacy of online randomized algorithms, with a versioned Zenodo record and a public implementation repository.

When to read this work

Use this artifact alongside the CCS 2023 paper when looking for the implementation of automata-based privacy checking or a versioned software citation.
