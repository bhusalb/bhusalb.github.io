# Research website maintenance

Publication pages, citation downloads, the JSON catalog, and per-paper `summary.md` files are generated from `_bibliography/papers.bib` and `_data/research.yml` by `_plugins/paper-pages.rb`. Markdown files are publication summaries and citation records, not full-paper reproductions. They include the available abstract, source links, related tutorials, and exact BibTeX.

Keep full-text links in `html_full_text` only after verifying that they open the actual paper. Each `questions` entry needs a concise `question`, a source-supported `answer`, and a `source_url` with a descriptive `source_label`. These entries appear on the paper page, in its Markdown summary, in the JSON catalog, and in `llms-full.txt`. Check source sections and publication status when updating them.

Run `bundle exec ruby bin/validate_research_site.rb` after a production build to check publication metadata, local links, citations, and consistency across the generated summaries.

`generate-social-cards.cjs` contains the editable HTML, CSS, and SVG source for the 1200 × 630 tutorial sharing images in `assets/img/research/`. The images are committed so normal Jekyll builds do not need Node or a browser.

To regenerate them with Node 20 or newer, install Playwright outside the repository and run the script with an installed Chrome executable:

```sh
npm install --prefix /tmp/site-social-card-tools playwright@1.64.1
NODE_PATH=/tmp/site-social-card-tools/node_modules \
  CHROME_EXECUTABLE="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  node bin/generate-social-cards.cjs
```

Pass a card's slug to generate only that image:

```sh
NODE_PATH=/tmp/site-social-card-tools/node_modules \
  CHROME_EXECUTABLE="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  node bin/generate-social-cards.cjs dipapprox-ccs25
```

On other systems, set `CHROME_EXECUTABLE` to the Chrome/Chromium executable. Alternatively, install Playwright's Chromium in a temporary directory and omit `CHROME_EXECUTABLE`:

```sh
PLAYWRIGHT_BROWSERS_PATH=/tmp/site-social-card-browsers \
  /tmp/site-social-card-tools/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/site-social-card-tools/node_modules \
  PLAYWRIGHT_BROWSERS_PATH=/tmp/site-social-card-browsers \
  node bin/generate-social-cards.cjs
```

After changing a card, inspect the generated PNG at its original size to check title wrapping, diagram labels, and cropping. Keep the matching tutorial's `og_image`, `og_image_alt`, and `twitter_card` front matter in sync.

The four SVG figures in the CCS 2025 DipApprox post are generated by `generate-dipapprox-figures.py`. Install Matplotlib in your Python environment, then run:

```sh
python3 bin/generate-dipapprox-figures.py --preview-dir /tmp/dipapprox-figure-previews
```

Only the optimization figure contains experimental measurements, transcribed from Table 2 of the paper. The Gaussian and interval figures are teaching examples. Preserve that distinction, the single-pair scope, and the timeout label when editing the plots. The SVGs include accessible descriptions and selectable text; the article provides captions and alt text.

The three Muon figures use the numerical functions in `assets/code/clipping_polar_geometry.py`. Regenerate them with Matplotlib:

```sh
python3 bin/generate-muon-figures.py --preview-dir /tmp/muon-figure-previews
```

These figures illustrate the same two matrices, without privacy noise or training measurements. The threshold slider in `assets/js/muon_clipping_explorer.js` computes their clipped mean and polar rotation for positive thresholds from 0.25 to 4.5. Keep its values consistent with the Python example when editing either implementation.
